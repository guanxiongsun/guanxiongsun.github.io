Collaborate

Open problems. Let’s work on them together.

I’m looking for collaborators (faculty, industry researchers and students) who care about memory in perception and action. If one of these is your problem too, write to me.

  1. I

    Efficient memory for long-horizon VLA policies

    Robot episodes run for minutes, and the world changes while they run. I bring memory-bank design from video (MAMBA, STPN).

    Good fit if you work on:
    • Robot learning
    • VLA
    • Long context
    Discuss this: Efficient memory for long-horizon VLA policies
  2. II

    Memory as architecture

    Architectural memory, such as token-indexed memory tables inside attention, meets episodic memory in agents. I’d like to test such mechanisms where memory is the bottleneck: long videos and embodied agents. Reading: e.g. Memory Attention (arXiv:2609.28399).

    Good fit if you work on:
    • Efficient attention
    • KV cache
    • Memory layers
    Discuss this: Memory as architecture
  3. III

    Video world models with persistent memory

    World models that keep a state of the scene across long rollouts, not just the last few frames.

    Good fit if you work on:
    • Video generation
    • World models
    Discuss this: Video world models with persistent memory
  4. IV

    Human motion and sign-language generation

    Building on Neural Sign Actors (led by colleagues at Imperial College London): more expressive hands and faces, and evaluation with Deaf and ASL-fluent signers.

    Good fit if you work on:
    • 3D humans
    • Accessibility
    Discuss this: Human motion and sign-language generation

On my desk

  • Memory Attention — J. Kang, arXiv:2609.28399 (2026). Builds attention values from token-indexed memory tables instead of a value projection. Why it matters to me: memory that is cheap to read is exactly what long-horizon VLA policies need.
